# Atmosphere theme format

A theme is one JSON file at `assets/<namespace>/atmospheres/<name>.json` in the mod jar or any resource pack. Its
id is `<namespace>:<name>`, for example `cosmeticsmod:ember_solstice`. The 13 built-in themes are in
`src/main/resources/assets/cosmeticsmod/atmospheres/`. They are generated by
`python3 tools/sol-assets/make_themes.py src/main/resources/assets/cosmeticsmod/atmospheres`, so edit that script
rather than the JSON.

Themes are loaded on startup and on every resource reload (F3+T). The built-in themes come first, in their `order`;
then pack themes, A–Z.

**What happens to bad input:**
- Every field is optional. A file holds only what differs from the defaults below, and a partial file merges over
  them.
- A wrong type or out-of-range value falls back to the default and is logged once for that file. The rest of the
  file still loads.
- A file that isn't JSON gives the defaults, under the file's id.
- Unknown fields are ignored.

```json
{
  "name": "Ember Solstice",
  "line": "A red sky, a haloed sun, sparks rising off the sand.",
  "order": 3,
  "ui": { "accent": "#ffb347", "panel": "#3c1608", "panelAlpha": 0.52, "rim": "#ffc878", "rimAlpha": 0.6 },
  "sky": { "top": "#5e0f06", "middle": "#7a1a07", "horizon": "#c2461a", "glow": "#fe8a2c", "sunWarmth": 0.35 },
  "fog": { "color": "#f08a3a", "density": 0.55, "bands": 4, "near": 2, "far": 34, "scatter": 1.0, "haze": 0.45 },
  "light": { "tint": "#ffe0b0", "strength": 0.7, "boost": 1.8, "sun": "#fff0cc", "shadow": "#6a3a48" },
  "grade": { "highlights": "#fff0d0", "shadows": "#46201a", "saturation": 0.97, "contrast": 1.0,
             "bloomTint": "#ffcc98", "bloom": 0.9, "threshold": 0.6, "vignette": 0.12 },
  "show": { "phase": "dusk", "azimuth": 90 },
  "sun": { "size": 0.042, "core": "#fff3c4", "halo": "#ffb347", "rays": 14, "coreRays": 9 },
  "stars": { "count": 40, "palette": "warm", "milkyWay": 0.3 },
  "clouds": { "tint": "#ff9a5c", "litBySun": true, "visible": false },
  "wind": [0.4, 0.0, 0.1],
  "particles": [ { "type": "ember", "count": 70, "colors": ["#ffb24a", "#ff7a2a", "#ffd27a"], "size": [1.4, 3.2] } ],
  "keyframes": { "day": { "sky": { "top": "#a8461e" }, "fog": { "near": 8, "far": 120 } }, "night": { "particleScale": 0.8 } }
}
```

## Conventions

- **Colours** are `"#rrggbb"` or `"#aarrggbb"`.
- **Sizes and screen positions** are the prototype's units: a fraction of the view's height.
  - The game turns them into angles with the current field of view. A prototype frame is 70° tall, and its
    horizon sits at 64% of the height.
  - So a `size` of 0.042 is about 2.9° of sky, before the sun's height scale.
  - `x`/`y` positions (sun, moon, galaxy, sigil, eclipse, nebulae) place the object in the theme's showpiece view:
    - azimuth = `show.azimuth + (x − 0.5) × horizontal FOV`;
    - altitude = `(0.64 − y) × 70°`.

## Top level

| Key | Default | Meaning |
|---|---|---|
| `name` | `"Theme"` | Shown in the menus. Built-in themes use the lang key `sol.theme.<id>.name` instead. |
| `line` | `""` | One-line description under the name. |
| `order` | 1000 | Sort order among themes. |
| `ui` | grey glass | Menu and HUD colours, below. |
| `sky`, `fog`, `light`, `grade` | a plain day | The world's look, below. |
| `sun`, `moon` | on | An object, or `null`/`false` for none. |
| `stars`, `planets` | natural | The stellar sky, below. |
| `galaxy`, `aurora`, `nebula`, `eclipse`, `sigil`, `mist` | none | Extras, below. |
| `lightning` | false | Monsoon's lightning: sky flash plus a pixel bolt. |
| `clouds` | vanilla | Cloud tint and visibility. |
| `wind` | `[0.2, 0, 0.05]` | Wind in blocks per second (x, y, z) for the theme's particles. |
| `particles` | none | Particle streams, below. |
| `show` | day, azimuth 0 | The showpiece moment and the direction it faces. |
| `flags` | | `noRidges` (no stepped fog bands on far land), `vanillaSun` (the game's own sun). |
| `keyframes` | none | Dawn, day, dusk and night versions, below. |

## `ui`

| Key | Meaning |
|---|---|
| `accent` | The theme accent: switches, lit icons, the selected slot, glows. |
| `panel`, `panelAlpha` | The glass colour and how dark it is. |
| `rim`, `rimAlpha` | The 1 px glass rim. |

## `sky`

The sky is a dome coloured by view elevation:
- `horizon` at the horizon;
- `middle` at 20°;
- `top` from 45° up.

| Key | Meaning |
|---|---|
| `top`, `middle`, `horizon` | The dome colours. At sunset a keyframe darkens the top; it never brightens it. |
| `glow` | The horizon glow band, and the warm side of the dome toward the sun. |
| `sunWarmth` | 0–1: how much the dome's lower rings warm toward the sun's azimuth (scaled by how low the sun is). |

## `fog`

| Key | Default | Meaning |
|---|---|---|
| `color` | `#c0d8ff` | Fog colour, and the dome below the horizon. |
| `density` | 0.2 | 0–1. Without `start`/`end`, sets them like the prototype's fogged terrain layers. |
| `start`, `end` | from `density` | Fog start and end as fractions of the render distance (used when `far` is 0). |
| `near`, `far` | 0 | Fog start and end in blocks. They win over `start`/`end` when `far` > 0. Ember pulls fog in so things about 20 blocks out read as silhouettes. |
| `scatter` | 0.3 | 0–2: light scattered in the fog, brighter and warmer toward the sun (Sol light pass). |
| `haze` | 0.2 | 0–2: extra scattering near the ground. |
| `bands` | 0 | 0–12: stepped fog bands on far land (Voxy), so each far ridge is paler than the one in front. |
| `voxyThinning` | 0 | 0–1: thins a dense theme's fog when Voxy or Distant Horizons draws far land. |

## `light`

The light on blocks. The game's sky light keeps its brightness but takes the tint's hue; then the boost
brightens it.

| Key | Default | Meaning |
|---|---|---|
| `tint` | white | Hue of the sky light. |
| `strength` | 0 | 0–1: how far the hue moves toward `tint`. Also scales the light pass's sunlight on blocks. |
| `boost` | 1 | 0.25–3: brightness of the sky light (golden hour). |
| `sun` | 75% `tint` | The colour of block faces turned to the sun (light pass, High). |
| `shadow` | from the sky | The colour of faces turned away (light pass, High). Backlit plants take its hue as silhouettes. |

## `grade`

The Sol light pass's colour grade and bloom. Not used while an Iris shader pack runs.

| Key | Default | Meaning |
|---|---|---|
| `highlights` | `#fff4e6` | Highlights are pulled toward this colour. |
| `shadows` | `#1e2230` | Shadows are lifted toward this colour. |
| `saturation` | 1 | 0–2.5. |
| `contrast` | 1 | 0.5–2, around the middle grey. |
| `lut` | none | A 1024×32 PNG (32 slices of 32×32: red across, green down, blue by slice) that replaces the generated grade. `namespace:path`. |
| `bloomTint` | white | Bloom colour. |
| `bloom` | 0.35 | 0–3: bloom strength. |
| `threshold` | 0.72 | 0–1: the brightness bloom starts at (raised automatically in a bright scene). |
| `vignette` | 0.18 | 0–1. Keep it subtle: the built-in themes use 0.1–0.2. |

## `sun`

`null` or `false` means no sun (Eclipse uses `eclipse` instead).

| Key | Default | Meaning |
|---|---|---|
| `texture` | `cosmeticsmod:atmosphere/sun` | The square sun's base texture. |
| `size` | 0.03 | Half the sun's size as a fraction of the view height. It is ×1.75 at the horizon, falling to ×1 high up. |
| `core`, `halo` | | Core and halo colours. Both are mixed with the height colours (`#ff6a2a` → `#ffd36b` → `#fff8ea`). |
| `haloRadius`, `haloAlpha` | 0.2, 0.3 | The wide soft halo. |
| `rays`, `coreRays` | 14, 9 | Rays in the two counter-rotating fans (0 for none). |
| `rayLength` | 1 | Ray length scale. |
| `plasma`, `corona`, `sunDogs`, `pillar`, `shimmer`, `flare`, `glare` | true | The Sun lab's layers. Each also has a player switch in Atmosphere. |
| `orbitTilt` | 0 | Tilt of the sun's path in degrees. |
| `x`, `y` | 0.74, 0.24 | Position in the showpiece view. |

## `moon`

| Key | Meaning |
|---|---|
| `size`, `color`, `halo`, `haloRadius`, `haloAlpha` | As for the sun. The moon has 8 real phases from the day number. |
| `ring` | The cold 22° ring on frosty nights. |
| `dogs` | Moon dogs. |
| `x`, `y` | Position in the showpiece view. |

## `stars` and `planets`

| Key | Default | Meaning |
|---|---|---|
| `stars.count` | 0 | Bright twinkling pixel crosses (0–2000); the baked star field is always there at night. |
| `stars.density` | 1 | 0–4: density of the baked field. |
| `stars.palette` | `natural` | `natural`, `mono`, `nebula`, `teal`, `silver`, `gold` or `warm`. |
| `stars.tint` | none | A colour every star is pulled toward. |
| `stars.milkyWay` | 0.5 | 0–1. |
| `stars.deepSky` | true | Clusters and nebula puffs. |
| `stars.shooting` | false | Frequent shooting stars (one every 2.5–5.5 s); otherwise rare. |
| `stars.meteorNights` | 7 | Every n-th night is a meteor shower (0: never). |
| `stars.comets` | true | A comet now and then, staying three nights. |
| `stars.through` | `clear` | `clear`, `cloudGaps` (Monsoon) or `fog` (Grace). |
| `planets.enabled` | true | Saturn, Jupiter, Mars and Venus on a tilted path; Zoom swaps in the detailed sprites. |
| `planets.style` | `natural` | Sprite style, e.g. `mono` for Deep Field's white-ringed Saturn. |
| `planets.tint` | none | |
| `planets.daytime` | `["venus"]` | Planets that show by day near sunset. |

## Extras

| Key | Shape | Meaning |
|---|---|---|
| `galaxy` | `{x, y, r, tilt}` | Deep Field's two-arm galaxy. |
| `aurora` | `["#colour", …]` | One ribbon per colour. |
| `nebula` | `[{x, y, r, color}]` or `[[x, y, r, "#colour"]]` | Nebula glows. |
| `eclipse` | `{x, y, size, corona}` | The black square sun with its burning ring. |
| `sigil` | `{x, y, r, color, halo}` | Grace's rune, with bloom, crackle, pillar and lit cloud. |
| `mist` | `{color, warm, bands, alpha}` | Mist bands drifting over the horizon. |

## `clouds`

| Key | Default | Meaning |
|---|---|---|
| `tint` | none | Cloud colour. |
| `litBySun` | true | Lit by a low sun. |
| `visible` | true | `false` hides the game's clouds while the theme is on, so they don't fight the sky (Ember). |

## `particles`

A list of streams. Each is an object, or the prototype's `["type", count, ["#colours"], [min, max]]`.

| Key | Default | Meaning |
|---|---|---|
| `type` | | `petal`, `blossom`, `leaf`, `snow`, `flake`, `ash`, `rain` (shaped), or `ember`, `dust`, `firefly`, `sparkle`, `lens`, `note` (glowing). |
| `count` | 40 | How many fill one view, as in the prototype. The box round the camera holds about five views' worth, within the quality's budget (Low 300, Medium 600, High 1,200 particles in all). |
| `colors` | white | Picked per particle. |
| `size` | `[1.5, 3]` | Size range, in the prototype's pixels. |
| `texture` | none | A sprite to use instead of the built-in shape. |
| `fall`, `spin` | 1 | Speed scales. |

**How they look:**
- **Glowing types** are smooth additive light: a bright core and a wide halo, brighter than white. Ones near the
  camera turn into soft bokeh.
- **Shaped types** have smooth edges. They are lit by the sun and glow through when backlit.
- **None of them** shows a square or hard edges; they fade near blocks.

## `show`

| Key | Meaning |
|---|---|
| `phase` | `dawn`, `day`, `dusk` or `night`: the theme's showpiece moment. The file's own values are this phase. |
| `azimuth` | The direction the showpiece faces, in degrees (90 = west). |

## `keyframes`

**Phases:**
- `dawn`, `day`, `dusk` and `night` each hold any of the fields above. They are merged over the file itself.
- The `show` phase is the file itself.
- A missing phase is also the file itself.

**Blending:**
- The game blends the phases by the sun's real height and the time of day, quantised to 1/256 of a day.
- `fog.near`/`far` blend in blocks. When only one side sets them, the other side's fractions of 192 blocks are
  used.
- `particleScale` (0–3) scales every stream's count in that phase.
- The grade always comes from the base theme.
