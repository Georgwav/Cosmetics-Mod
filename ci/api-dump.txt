# Used by the "api-dump" CI job (runs when a commit message contains [api-dump]).
# One line per Minecraft build: <version> <comma-separated classes>. Prints `javap -protected` for each
# class as that version's Minecraft (Mojang names) has it. Handy when porting to a new version.
#
# Example:
# 26.3 net.minecraft.client.renderer.entity.state.AvatarRenderState,net.minecraft.client.renderer.SubmitNodeCollector
# A class starting with ! also prints private members and bytecode.
1.21.1 !net.minecraft.client.gui.screens.inventory.InventoryScreen
1.21.8 !net.minecraft.client.gui.screens.inventory.InventoryScreen
1.21.11 !net.minecraft.client.gui.screens.inventory.InventoryScreen
26.1.2 !net.minecraft.client.gui.screens.inventory.InventoryScreen
26.3 !net.minecraft.client.gui.screens.inventory.InventoryScreen
