# Used by the "api-dump" CI job (runs when a commit message contains [api-dump]).
# One line per Minecraft build: <version> <comma-separated classes>. Prints `javap -protected` for each
# class as that version's Minecraft (Mojang names) has it. Handy when porting to a new version.
#
# Example:
# 26.3 net.minecraft.client.renderer.entity.state.AvatarRenderState,net.minecraft.client.renderer.SubmitNodeCollector
# A class starting with ! also prints private members and bytecode (!Class#text: only the members whose line
# contains the text); ~Class prints private members without bytecode; ?text lists resource files whose path
# contains the text (e.g. ?cape).
26.3 !net.minecraft.client.renderer.LevelRenderer#utline,net.fabricmc.fabric.api.client.rendering.v1.SubmitRenderPhase,net.fabricmc.fabric.api.client.rendering.v1.SubmitRenderPhases,net.minecraft.client.renderer.*
26.1.2 !net.minecraft.client.renderer.LevelRenderer#utline,net.fabricmc.fabric.api.client.rendering.v1.*
26.2 net.fabricmc.fabric.api.client.rendering.v1.world.*
