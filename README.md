# Sol Client look sheets

Contact sheets for georgwav/cosmetics-mod#31. They come from a local look run on 1.21.11 at 1280×720, with Pixel light (the default).

- `sol-sheet-a.png`, `sol-sheet-b.png`: every theme's showpiece, day and night, each next to the Ember Sun lab frame (the bar).
- `sol-intensity.png`: the Ember frame with Atmosphere intensity at 100%, 50% and 0%.
- `frames/`: the showpieces at full size.
